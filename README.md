# Цахим урилга — Сэвлэг үргээх ёслол

Монголхүү · Хүннү зоогийн газар. Хөтөлбөр, санамж, RSVP.

Нэг файл: `index.html`. Build хэрэггүй, суулгах зүйлгүй.
**Давхар товшвол шууд нээгдэнэ.**

Гаднаас татдаг зүйл нь ердөө хоёр: Google Fonts (Spectral, Onest) ба GSAP (CDN).
Хоёулаа `https` хаягтай тул `file://`-ээс ч ажиллана. Интернэт шаардлагатай.

---

## Өөр арга хэмжээнд дахин ашиглах

Бүх текст файлын `<script>` доторх **`CONFIG` объектод** байна. Ихэнх тохиолдолд
зөвхөн түүнийг л солино — доорх кодыг хөндөх шаардлагагүй.

### CONFIG-ийн бүтэц

| Талбар | Юу вэ |
|---|---|
| `ceremony.title` | Ёслолын нэр. Табны гарчигт бас орно |
| `child.name` | Хүүхдийн нэр. Hero-д том үсгээр гарна |
| `child.age` | «3 нас» гэх мэт. Нэрийн доор шугамтай хамт |
| `parents.line` | Hero-гийн доод буланд, баруун талд |
| `date.iso` | **Countdown үүнээс тоолно.** ISO 8601, цагийн бүстэй |
| `date.display` / `weekday` / `hour` | Hero-д харагдах огноо, гараг, цаг |
| `venue.place` / `city` / `hall` | Байршлын нэр, хот, танхим |
| `venue.mapsUrl` | Google Maps-ийн шууд холбоос. `null` бол `mapsQuery`-ээр хайлт үүсгэнэ |
| `opening.line` | Нээх дэлгэцэн дэх шүлгийн мөр |
| `opening.hint` | «ХҮРЭЭРЭЙ». `null` болговол бүрэн алга болно |
| `opening.stars` / `shards` | Одны тоо. Хөгшин утсанд хүндэрвэл багасга |
| `hero.above` / `below` / `verse` | Нэрийн дээд мөр, доод мөр, шүлэг (массив) |
| `countdown.label` / `passed` / `units` | Тоолуурын гарчиг, огноо өнгөрсөн үеийн мөр, нэгжүүд |
| `program.label` / `items[]` | Хөтөлбөр. Мөр бүр `{ time, title, note }` |
| `place.label` / `cta` | Байршлын гарчиг, товчны бичиг |
| `manners.label` / `items[]` | Санамжууд. Мөр бүр `{ title, text }` |
| `rsvp.*` | Маягтын бүх бичиг (доор дэлгэрэнгүй) |
| `closing.line` / `signature` | Төгсгөлийн ерөөл, гарын үсэг |
| `galleryLabel` / `gallery[]` | Зургийн цомог (доор дэлгэрэнгүй) |

### Гараар бас солих ёстой ганц зүйл

Табны гарчиг, тайлбарыг CONFIG өөрөө шинэчилдэг. Гэхдээ **Facebook, Messenger
зэрэг холбоосын урьдчилсан харагдац JS ажиллуулдаггүй.** Тиймээс урилгаа
тараахаас өмнө `<head>` доторх статик хоёр мөрийг бас гараар засна:

```html
<title>Сэвлэг үргээх ёслол · Монголхүү</title>
<meta name="description" content="...">
```

## Ирцийг жинхэнэ болгох

Анхдагчаар `CONFIG.rsvp.endpoint` нь `null` — маягт хаашаа ч явахгүй, зөвхөн
дэлгэцэн дээр «Таны үг хүрлээ.» гэж харуулна. Туршихад тохиромжтой.

Жинхэнэ болгохын тулд хаяг өг:

```js
endpoint: 'https://таны-сервер/rsvp'
```

Дараа нь дараах JSON POST-оор очно:

```json
{ "name": "...", "attend": "yes", "count": "3", "wish": "..." }
```

Сервер `200` буцаавал амжилттай гэж үзнэ. Өөр бүх тохиолдолд маягт байрандаа
үлдэж, `CONFIG.rsvp.errorText` мөр гарч, товч дахин идэвхжинэ.

> Google Forms, Google Apps Script, Formspree зэрэгт холбож болно.

## Зураг нэмэх

`CONFIG.gallery` хоосон байхад цомгийн секшн **байхгүй мэт нуугддаг**. Зураг
нэмэхэд өөрөө нээгдэнэ:

```js
gallery: [
  { src: 'zurag/01.jpg', alt: 'Ёслолын өглөө' },
  { src: 'zurag/02.jpg', alt: '' }
]
```

Зургуудаа `index.html`-ийн хажууд тавь. 2 баганат тор, 3:4 харьцаатай.

## Өнгө, шрифт солих

Бүх утга `:root` доторх токенд байна. Нэг газраас солиход хуудас бүхэлдээ дагана.

```
--night    #070C1A   нээх дэлгэц
--morning  #14243C   од хүрсний дараа
--day      #21486F   цэнхэр тэнгэр
--steppe   #27503C   ногоон тал
--amber    #E9A45C   ГЭРЭЛ — тоолуур, идэвхтэй товч, тайралт
--milk     #F3EFE6   үндсэн текст
```

Дэвсгэрийн зам JS-д биш, эдгээр токеноос уншигддаг тул `--day`, `--steppe`-г
сольход гүйлгэх аялал өөрөө шинэчлэгдэнэ.

**Анхаар:** дэвсгэрийг цайруулбал `--muted` бүхий жижиг шошгын тодролт унана.
Одоогийн утга (.72) нь хамгийн гэрэлт дэвсгэр дээр 4.99:1 — WCAG AA-гийн
босгыг дөнгөж давж байгаа.

## Өөрөө зохицдог зүйлс (гар хүрэх шаардлагагүй)

- **Хүүхдийн нэр** баганад багтахгүй бол шрифтийн хэмжээ өөрөө буурна.
  14 үсэгтэй нэр ч ажиллана.
- **Шүлгийн мөр** таслагдахаар бол мөн адил өөрөө буурна. Зөвхөн шаардлагатай үед.
- **Countdown** огноо өнгөрөхөд 4 нүдээ `countdown.passed` мөрөөр солино.
- **Ёслолын ёсны икон** нь мөрийн дугаараар таардаг бөгөөд 4 ширхэг бий
  (хайч, үнэртэй ус, дээл, гэрэл зураг). 5 дахь мөр бичвэл иконгүй, зөвхөн
  текстээр гарна — хоосон дөрвөлжин үлдэхгүй.
- **`prefers-reduced-motion`** асаалттай зочинд нээх дэлгэц бүрэн алгасагдаж,
  бүх агуулга шууд харагдана.
- **GSAP татагдаагүй** бол мөн адил — хуудас анимейшнгүйгээр бүтэн ажиллана.
